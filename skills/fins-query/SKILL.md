# 财报数据查询

数据目录：`workspace/fins/{ticker}/`（ticker 为股票代码，如 `600519`）。

数据结构详情见 [references/data-schema.md](references/data-schema.md)。

## 查询策略

### 按目录定位（推荐）

适用：知道大概在哪个章节。

1. grep `index.json` 的 `title` → 找章节 `ref`
2. grep `sections.json` 中该 `ref` → 读正文
3. 正文遇 `[表格 t_xxx]` → grep `tables.json` 取数据

### 全文搜索

适用：关键词明确但不知章节位置。

1. grep `full.md` 找关键词
2. 根据上下文定位章节
3. 去 `sections.json` 读完整上下文

### 表格直查

适用：明确要数据型信息。

1. grep `tables.json` 的 `caption` / `headers` → 找表格 `ref`
2. 直接读 `headers` + `rows`

## 查询闭环示例

用户问：“贵州茅台 2024 年营收和净利润是多少？”

1. 确认数据目录：`workspace/fins/600519/`
2. grep `index.json`：
   - 先搜 `主要会计数据`、`营业收入`、`净利润`
   - 记录命中的章节 `ref`，例如 `s_003`
3. 读取 `sections.json` 中的 `s_003`：
   - 提取正文中的关键句
   - 如果看到 `[表格 t_005]` 这样的占位符，继续查表格
4. 读取 `tables.json` 中的 `t_005`：
   - 用 `headers` 判断列含义
   - 用 `rows` 定位“营业收入”“归属于上市公司股东的净利润”等行
5. 回答时说明：
   - 数值、单位、报告期
   - 数据来自哪个章节/表格 ref
   - 如果表格口径不清楚，提醒用户需核对原 PDF
